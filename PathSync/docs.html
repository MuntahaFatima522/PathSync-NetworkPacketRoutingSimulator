Dijkstra's Shortest Path Routine

Dijkstra's algorithm is a greedy pathfinder designed to find the shortest path from a single source node to all other nodes in a weighted graph. It behaves as a Breadth-First search using a **Priority Queue** to prioritize visiting nodes with the lowest accumulated cost.

function Dijkstra(Graph, source): dist[v] = Infinity # Initialize distances prev[v] = null # Initialize routing paths dist[source] = 0 pq = MinHeap() pq.push((0, source)) while pq is not empty: (d, u) = pq.pop() if u is visited: continue mark u as visited for each neighbor v of u: if dist[u] + w(u,v) < dist[v]: dist[v] = dist[u] + w(u,v) # Relaxation step prev[v] = u pq.push((dist[v], v)) return dist, prev

Complexity: Dijkstra's execution runs in $O(V^2)$ on standard arrays, but improves to $O(E \log V)$ using binary min-heaps. It is highly efficient for sparse layouts.
Limitation: Fails on negative edge weight paths because once a node is visited, its cost is assumed finalized.

Bellman-Ford Relaxer Routine

Bellman-Ford is a dynamic programming algorithm that solves the single-source shortest path problem on weighted graphs. Instead of grease-visiting nodes, it repeatedly relaxes all edges $V - 1$ times.

function BellmanFord(Graph, source): dist[v] = Infinity; dist[source] = 0 prev[v] = null for i = 1 to V - 1: for each edge (u, v, w): if dist[u] + w < dist[v]: dist[v] = dist[u] + w # Relax edge prev[v] = u # Negative loop cycle check for each edge (u, v, w): if dist[u] + w < dist[v]: return "Negative cycle detected!" return dist, prev

Complexity: Execution runs in $O(V \cdot E)$. It is slower than Dijkstra on large graphs but guarantees correctness under negative link constraints.
Benefit: Explicitly detects negative weight loop cycles, protecting against looping route failure conditions.

Industrial Routing Protocols

Shortest path routing algorithms form the backbone of core Internet routing standards. The two most popular interior gateway routing protocols map directly to our simulation modes.

Protocol Specs OSPF (Open Shortest Path First) RIP (Routing Information Protocol)
Underlying Engine Dijkstra (Link-State Pathfinder) Bellman-Ford (Distance-Vector)
Telemetry Topology Builds full layout tree locally Knows neighbors and distance vectors
Convergence Rate Rapid (Updates on change triggers) Slow (Periodic timed broadcasts)
Max Edge Limit No limit (Constrained by local memory) 15 Hop count limit (16 is unreachable)
Link Metric (Weight) Interface Cost (Bandwidth based) Hop count (Each router counts as 1)
